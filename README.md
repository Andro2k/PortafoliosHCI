# Portafolios HCI

Tres propuestas de portafolio personal con estilos visuales diferentes. Abre cada una para explorar su presentación, trayectoria y medios de contacto.

| Versión | Estilo | Enlace |
| --- | --- | --- |
| **01 · Original** | Interfaz tecnológica con tema claro y oscuro. | [Ver portafolio](portafolio01/index.html) |
| **02 · Editorial** | Composición cálida, tipografía protagonista y acentos terracota. | [Ver portafolio](portafolio02/index.html) |
| **03 · Lovable** | Versión publicada en Lovable. | [Abrir sitio](https://theandro2k.lovable.app/) |
